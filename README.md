# Часы вселенной (Clock of the Universe) — мод для Minecraft 1.21.1 / NeoForge

## Что делает мод
* Добавляет предмет **«Часы вселенной»** (`universeclock:universe_clock`).
* **Крафт** (как у обычных часов): золотые слитки — сверху, снизу, слева и справа, алмаз — в центре.

```
  [Зол.слиток]
[Зол.слиток] [Алмаз] [Зол.слиток]
  [Зол.слиток]
```

* **ПКМ с часами в руке** открывает меню настройки времени суток:
  * цифровое табло **ЧЧ:ММ:СС** — колесо мыши, стрелки ▲▼, клавиши ↑/↓ или прямой ввод цифр
    (после двух цифр курсор сам переходит на следующее поле), **Shift** — крупный шаг;
  * «небесная шкала» — 24 часа в виде неба (ночь → рассвет → день → закат), можно кликать и тянуть мышью;
  * пресеты: Рассвет, Утро, Полдень, Закат, Ночь, Полночь;
  * кнопка «Текущее» — взять время мира, «Применить» (или Enter) — установить время.
* Меню не ставит игру на паузу — небо меняется у вас на глазах.
* Номер суток (и фаза луны) сохраняются — меняется только время внутри суток.

> Про «секунды»: в Minecraft время хранится в тиках (сутки = 24000 тиков, тик 0 = 06:00:00).
> На циферблате 24 часа это 3,6 секунды на тик, поэтому введённое время округляется до ближайшего тика.
> Под табло всегда показан фактический тик и время, которое реально установится.

## Как собрать .jar
Нужен **JDK 21** (например, Temurin 21) и интернет (Gradle сам скачает NeoForge).

```bash
# Linux / macOS
./gradlew build

# Windows
gradlew.bat build
```

Готовый файл: `build/libs/universeclock-1.0.0.jar` — положите его в папку `mods` (NeoForge 21.1.x для Minecraft 1.21.1).
Мод нужно установить и на клиент, и на сервер.

Запуск для разработки: `./gradlew runClient`.
Если залить проект на GitHub, jar соберётся автоматически (вкладка Actions → Artifacts).

## Структура
* `UniverseClockMod` — регистрация предмета и сетевого пакета
* `item/UniverseClockItem` — предмет (ПКМ открывает меню)
* `client/UniverseClockScreen` + `TimeField`, `SkySlider`, `FlatButton`, `Gfx` — интерфейс
* `network/SetTimePayload`, `ServerPayloadHandler` — установка времени на сервере (проверяет, что часы в руке)
* `TimeUtil` — перевод тиков ↔ ЧЧ:ММ:СС
* `data/universeclock/recipe/universe_clock.json` — рецепт (легко поменять)
